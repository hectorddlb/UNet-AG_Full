# Evaluation

The **single** protocol with which the six methods of the thesis are measured.
No reported number comes from any other chain.

```
image → envelope → dB, 60 dB dynamic range
      → env_log normalized to [0,1]
      → bilinear interpolation to the 612×388 grid
      → _eval_image  (per-wire lat/ax FWHM, CNR in dB, gCNR)
```

The figures are drawn from the **same arrays** that feed the metrics
(`npys_eval_grid/`), never from a second pass.

## Contents

| Path | What it is |
|---|---|
| `scripts/gen_classical_picmus_fixed.py` | Reconstructs DAS 1/75 PW and Fd-F 1/75 PW with the corrected transmit convention |
| `scripts/gen_b1v5_picmus_seeds.py` | Inference of the proposed model, 3 seeds (and the Fd-F adjoint, its input) |
| `scripts/gen_drus_picmus.py` | DRUS with the thesis conditions (`drus` package) |
| `scripts/eval_and_figs_final.py` | Applies the protocol and produces metrics, tables and the `npys_eval_grid/` arrays |
| `scripts/run_final_results.sbatch` | The four previous stages in one SLURM job |
| `scripts/eval_beta_sweep_canonical.py`, `eval_anchor_candidates.py` | β sweep and metrics of the Fd-F adjoint (anchor image) |
| `scripts/computational_cost.py` | Analytic GFLOP per scenario |
| `scripts/inference_time.py`, `bench_cost.sbatch` | Wall-clock times on GPU |
| `scripts/verify_*.py` | Verifications: transmit convention, 1 PW Fd-F vs the adjoint, Field II partition and grid |
| `scripts/align_targets_to_train_grid.py`, `precompute_schiffner_targets_fieldii_fixed.py` | Corrected targets of the control experiment |
| `metrics/` | CSV and JSON with the reported results |
| `npys_eval_grid/` | 612×388 `env_log` of the 6 methods × 4 phantoms — source of metrics and figures |
| `matlab_validation/` | Validation of the Fd-F port against the MATLAB reference implementation |
| `verification/` | Results of the verifications (arrays, images and JSON) |
| `supervision_control/` | CSVs of the two control experiments with the corrected supervision |

## Metrics

| File | Supports |
|---|---|
| `metrics_picmus_final.csv` | Quality, hypothesis, seed and 1 PW reconstruction tables |
| `metrics_beta_sweep.csv`, `metrics_anchor_candidates.csv` | Table and figure of the β sweep (with the adjoint row) |
| `computational_cost.json`, `cost_per_scenario.csv` | Cost tables (experimental scenario and the three scenarios) |
| `inference_time_fp32.json` | Times of the cost table: the six methods in the experimental scenario, same node, fp32 |
| `inference_time_fp32_cold_load.json` | Earlier run on the same node with a cold load of the DRUS `Vᵀ` (~105 s) |
| `metrics_fidelity.csv` | Fidelity table (PSNR and SSIM vs DAS 75 PW) |
| `grids_picmus.json` | Evaluation grids, to redraw without the datasets |

`comparison_table.md` is the summary generated by `eval_and_figs_final.py`;
the CSVs are the reference.
